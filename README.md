# 📖 Project Overview

The Trucking Management System is a desktop application designed to digitalize trucking and logistics operations. The system provides an organized platform for managing drivers, trucks, shipments, and users through a graphical user interface connected with SQL Server database.

The application eliminates manual paperwork and improves record management efficiency through CRUD operations and database connectivity.
